# dsh-sidebar-toggle

Quickly toggle the DeepSeek Harness Web UI sidebar grouping between **workspace** (`工作区`) and **flat list** (`会话`).

## Features

1. **Shortcut `Alt+R`** — Toggle sidebar grouping (`workspace` ↔ `flat`) from anywhere.
2. **Click Header Title** — Click the sidebar section header text (`会话` / `工作区` / `Sessions` / `Workspaces`) to quickly toggle grouping.
